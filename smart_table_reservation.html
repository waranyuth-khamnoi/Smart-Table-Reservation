เฟส 1 • Planning สัปดาห์ที่ 1

อะไรคุ้มที่จะทำ?

กำหนดขอบเขต MVP ระบบจองโต๊ะ วางแผนงาน 10 สัปดาห์ และประเมินงบประมาณ

ผลลัพธ์: งานรอบแรก (MVP) + แผน
เฟส 2 • Requirements สัปดาห์ที่ 2

ผู้ใช้ต้องการอะไร?

เก็บความต้องการเลือกวัน เวลา จำนวนคน และเงื่อนไขจัดสรรโต๊ะอัตโนมัติ

ผลลัพธ์: User Story การจอง
เฟส 3 • Design สัปดาห์ที่ 3–4

ระบบจะทำงานอย่างไร?

ออกแบบหน้าจอ UI/UX การจองและหน้ายืนยัน ออกแบบฐานข้อมูลโต๊ะและ API

ผลลัพธ์: แบบหน้าจอและ API
เฟส 4 • Development สัปดาห์ที่ 5–7

จะสร้างร่วมกันอย่างไร?

พัฒนาโค้ดอัลกอริทึมจัดโต๊ะว่าง ระบบฐานข้อมูลเรียลไทม์ และบัตรยืนยัน QR Code

ผลลัพธ์: โค้ดที่รวมกันแล้วใช้ได้
เฟส 5 • Testing สัปดาห์ที่ 8

ตรงโจทย์และไม่พังหรือยัง?

ทดสอบการจองพร้อมกันหลายเครื่อง (Concurrency) ป้องกันการจองโต๊ะซ้ำซ้อน

ผลลัพธ์: หลักฐานทดสอบระบบ
เฟส 6 • Deployment สัปดาห์ที่ 9

ส่งให้ใช้งานจริงอย่างไร?

ติดตั้งระบบขึ้นเซิร์ฟเวอร์จริง ตั้งค่าโดเมน ความปลอดภัย และเปิดให้ลูกค้าจอง

ผลลัพธ์: ระบบที่ผู้ใช้ใช้ได้จริง
เฟส 7 • Maintenance สัปดาห์ที่ 10+

จะเรียนรู้และแก้อะไรต่อ?

เก็บสถิติการใช้งานจริง อัตราเต็มโต๊ะ และฟีดแบ็กเพื่อพัฒนาต่อในรอบถัดไป

ผลลัพธ์: รายการสิ่งที่ต้องแก้ต่อ
หัวใจการทำงาน

ส่งมอบคุณค่า แล้วเรียนรู้ต่อเนื่อง

เปิดใช้งานจริงให้เร็ว วัดผลจากผู้ใช้จริง และปรับปรุงอย่างต่อเนื่อง

โครงสร้างทีมงาน 5 ตำแหน่งหลัก

ตำแหน่งงาน เฟสหลัก หน้าที่ความรับผิดชอบ
1. Project Manager (PM) Planning, Deployment วางแผน MVP คุมงบ 380,000 บาท และส่งมอบระบบ
2. Business Analyst (BA) Requirements เขียน User Story และเงื่อนไขการจัดสรรโต๊ะว่าง
3. UX/UI Designer Design ออกแบบหน้าเลือกวัน-เวลา จำนวนคน และบัตรยืนยัน
4. Full-Stack Developer Development, Maintenance เขียนโค้ด Frontend/Backend อัลกอริทึมจัดโต๊ะและฐานข้อมูล
5. QA Tester Testing ทดสอบการจองพร้อมกันหลายเครื่องและระบบแจ้งเตือน
